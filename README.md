# TamperStation
Tamper Station Docs

This tamper station raises the tamping of your portafilter to a new level. The most common mistakes when tamping are not applying a level pressure to the coffee powder or applying too much or too little pressure. This leads to channeling and bad coffee.

<img src="Images/Portafilters.jpg" width="650">

This tamper station ensures a consistently horizontal tamper result. At the same time, you can read the current pressure on a scale at the top.
